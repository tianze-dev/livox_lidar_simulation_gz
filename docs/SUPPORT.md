# 支持范围

版本：0.1.0 预发布版。型号支持与近似参数如下。

| 型号 | 扫描与接口 | 外观与外参 | 支持状态 |
|---|---|---|---|
| MID-360 | 40 组循环预设；20000 射线/帧；10 Hz 点云；200 Hz 理想 IMU；静态、双实例、移动滑台测试 | 精细材质网格；手册名义外参；近似惯量 | 已支持 |
| Avia | 40 组非重复模式预设循环；24000 射线/帧；10 Hz 点云；200 Hz 理想 IMU；静态和移动测试 | 官方 CAD 衍生精细外观、近似材质和轻量碰撞；测量中心、IMU 外参和惯量近似 | 精细外观与扫描／接口预览；非完整硬件复现，公开资产再分发条件待确认 |
| MID-40／MID-70／Horizon／Tele | 上游有相关预设，本包不启用 | 未配套、未验收 | 不支持 |
| HAP | 缺少已接入的 RGL 预设 | CSV 转换未实现 | 不支持 |

两种已接入型号都仅返回单次几何求交结果，不模拟 strongest、双／三回波、探测概率、测距噪声、波束散角、通信协议或硬件反射率。Avia 重复线扫描模式未实现。有限文件循环不等于无限不重复扫描。

Avia 参数来源：[官方规格](https://www.livoxtech.com/avia/specs)、[官方手册入口](https://www.livoxtech.com/avia/downloads)及固定 RGL 上游预设。外形标称 91×61.2×64.8 mm、质量 498 g；按官方 CAD 对齐后主体 x=91、y=61.2、z=64.8 mm，+X 朝前窗，侧面接口计入后 y 方向约 75.55 mm。测量与 IMU 原点仍近似置于主体中心，明确不冒充厂家坐标标定。190 m 是本包固定量程截断，不能理解为所有表面都能真实探测到该距离。模型来源、变换和材质降级说明见 [Avia NOTICE](../meshes/avia/NOTICE.md)。

## 平台

- 原生目标：Ubuntu 24.04 x86_64、ROS 2 Jazzy、Gazebo Harmonic。
- 后端：RGL Core v0.21.0；需要 NVIDIA GPU 和兼容驱动。当前实测 RTX 4060、580.178.04。
- 基础源码构建和不调用 GPU 的单元测试可以在无 GPU 的容器里执行；实际仿真不提供 CPU 替代后端。
- Windows、macOS、ARM、Gazebo Classic、ROS 1、其他 GPU／驱动组合没有验收。
- Docker 基础镜像固定摘要；系统包由构建时 apt 源提供，因此不宣称跨日期逐字节可复现。测试时保存镜像 ID 与软件版本。

## 功能边界

CustomMsg、FAST-LIVO2、逐点时间、历史位姿与运动畸变、CSV 转换、实物标定均未实现。移动滑台验证的是整帧快照、动态 TF 与理想 IMU，不是去畸变或定位算法精度验收。

运行回归覆盖静态单实例、双 MID-360、混合型号，以及有限轨迹的移动、暂停、步进和复位。移动测试检查整帧点云几何、关节反馈、TF 和理想 IMU。

稳定性测试时长为 MID-360 300 秒、Avia 60 秒，不代表长期耐久保证。实测硬件范围仅限上述主机，容器验证不等于异机验证。复现方式见 [贡献规范](../CONTRIBUTING.md)。
