# MID-360 基础版验证记录

日期：2026-10-08。本记录对应当前基础实现，不代表正式开源发布或全系列验收。

## 已实现

- 仓库根目录单一 ament ROS 包，不加载其他机器人工作空间。
- 固定 RGL 插件提交、Core v0.21.0、API 头和 MID-360 预设；SHA256 校验、离线缓存与自定义缓存目录。
- RGL GPU 快照扫描，标准 PointCloud2、理想 Gazebo IMU、仿真时钟和固定 TF。
- 通用挂载宏、仅桥接的传感器入口、独立 demo、可选 Gazebo GUI／RViz 启动参数。
- 简化 MID-360 几何外观、盒体碰撞和外部网格参数。精细 CAD／彩色网格尚未迁入。

## 本机结果

环境：Ubuntu 24.04.5、ROS 2 Jazzy、Gazebo Sim 8.15.0、RTX 4060、驱动 580.178.04。
构建与测试使用清空继承环境的 shell，只加载 `/opt/ros/jazzy` 和本仓库自己的安装空间。

| 检查 | 结果 |
|---|---|
| 独立构建与安装 | 通过；插件从本仓库源码编译，RGL 库从固定公开发行下载 |
| 缓存离线校验 | 通过；ZIP、API 头、预设及解包库哈希匹配 |
| 单元测试 | 19 项通过，包括参数拒绝、缓存完整性、Xacro、传感器 SDF 保留和初始世界生成 |
| 真实 GPU 扫描 | 通过；日志确认使用 RTX 4060 和 RGL 0.21.0 |
| 点云字段 | x/y/z/intensity，float32，point_step=16，长度与布局一致 |
| 点云频率 | 仿真时间约 10 Hz |
| IMU 频率 | 仿真时间约 200 Hz；静止 z 比力 9.80665 m/s² |
| 已知几何 | 检查帧包含 4115 个有效点，其中 3464 点命中 x=3.9 m 的墙面（容差 0.01 m） |
| 时钟与 TF | 收到 /clock，三个传感器固定 frame 与安装位置检查通过 |
| 全场景复位 | 通过；显式恢复运行后观察到时间回退及至少 12 帧新的有效点云 |

频率来自相邻消息仿真时间戳，不是墙钟吞吐率或性能保证。点数是该测试帧结果，不是固定设备点数。首段采样收集 12 帧点云、240 条 IMU 和 1199 条时钟消息。

最终 GPU 记录位于本机 `run/smoke_initial_world/result.json` 和对应 `launch.log`，它们是忽略的运行产物，不是发行资产。可复现命令见 README。测试结束后关闭自身进程，未修改或终止其他工程。

## 修复与回归

1. 固定传感器链接缺少惯性时，Gazebo URDF 转换丢弃传感器。现增加极小数值链接惯性，保持标称总质量，并增加 SDF 转换回归。
2. 雷达外壳位于另一链接时会遮挡自身射线。现将外观放在传感器链接下，复用上游自链接过滤，保持其他机器人部件的遮挡。
3. Gazebo 全场景复位会移除初始世界之后创建的模型。demo 现将转换后的传感器模型放入私有临时初始世界，退出时清理；父项目的运行时生成／重新生成机器人仍由父项目负责。
4. RGL 场景与传感器增加 ISystemReset 和资源清理。场景复位重建 GPU 几何，传感器保留图并重置帧调度；未增加历史位姿或逐点时间。

早期失败日志保留在 run 下相应目录，用于追踪；不把失败的旧结果当作当前通过结果。
