# MID-360 模型来源与参数

## 来源与分发依据

项目所有者于 2026-10-09 确认原始 `mid360_base_link.STL` 来自官方模型且可以公开发布。该确认是本仓库的收录依据，不是 Livox 另行签发的许可证；官方模型、名称与标识不重新授权为本项目原创资产。

- 官方入口：[Livox MID-360 Downloads](https://www.livoxtech.com/mid-360/downloads)。
- 原 STL SHA256：`1fad48d70c34846e32dc2376782c875bea04b9ae0c2969515592469e4fab3e02`。
- 运行网格哈希、单位、轴向及包围盒见 `geometry_report.json`。

模型经过刚体配准、面朝向修正、配色和近似文字重建，没有非均匀缩放。银灰、蓝青、黑色与紧固件材质参考产品照片，以 COLLADA Phong 表达；不代表实测光学参数、精确品牌字体或 LiDAR 反射率。原 CAD 与模型制作工程不随运行资源分发。

可选的 `mid360.glb` 来自同一修复上色版本，保留 84766 个三角形及 PBR 金属度／粗糙度，导出后为 8 个实际使用的材质（DAE 声明 9 个材质，其中一个未使用）。GLB 采用 Y-up，Gazebo 加载时需 `mesh_rpy="1.5707963267948966 0 0"`，补偿后与 DAE 的安装坐标一致。默认仍使用 DAE；两种格式适用相同来源和分发说明，哈希见 `geometry_report.json`。

## 坐标与尺寸

名义外参来源：[Livox Mid-360 User Manual v1.2，2024.04](https://terra-1-g.djicdn.com/851d20f7b9f64838a34cd02351370894/Livox/Livox_Mid-360_User_Manual_EN.pdf)，印刷页 12、15、19。手册 SHA256：`3f202c845330023d50eee086cc522918ec8b1279446c4286ea3d38722400cab2`。

| 坐标项 | 约定或名义值 |
|---|---|
| 安装原点 | 外壳安装底面中心 |
| 轴向 | +X 朝正面标识侧，接口在 -X；+Z 向上；+Y 满足右手系 |
| 雷达相对安装原点 | `(0, 0, 0.047)` m |
| IMU 相对雷达 | `(0.011, 0.02329, -0.04412)` m，轴向相同 |
| IMU 相对安装原点 | `(0.011, 0.02329, 0.00288)` m |

整体网格约 72.737×64.874×60.127 mm，长度包含接口；官方主体名义尺寸为 65×65×60 mm，含接口长度为 73 mm。底面归零，包含文字后共 84766 个三角形、9 个材质。网格保留原有孔洞和开放曲面，不是单一闭合实体。

碰撞使用 65×65×60.2 mm 盒体及接口位置半径 6.2 mm、长度 8 mm 的圆柱，不使用精细网格参与物理碰撞。测试检查碰撞包络覆盖全部可视顶点及主体面朝向。

总质量采用官方标称 0.265 kg；质心与惯量为均匀盒体近似。几何配准与手册名义外参均不代替实物标定。
