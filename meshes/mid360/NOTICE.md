# MID-360 模型来源与处理说明

## 来源与发布依据

项目所有者于 2026-10-09 明确确认：原始 `mid360_base_link.STL` 来自官方提供的模型，可以公开发布。本仓库依据该确认收录精细模型；此说明记录所有者的来源及权限确认，不冒充 Livox 另行签发的许可证，也不将官方模型、名称或标识重新授权为本项目原创资产。

- 官方模型入口：[Livox MID-360 Downloads](https://www.livoxtech.com/mid-360/downloads)。
- 原 STL SHA256：`1fad48d70c34846e32dc2376782c875bea04b9ae0c2969515592469e4fab3e02`。
- 输入彩色 Blender SHA256：`ce2f09c4dc120a688d301f354390918ea352254c4fd92c09d5981636d274b0aa`。
- 本仓库精简制作源 `source.blend` SHA256：`ac80b9d9038b5d5d157544167ab4a307c4db96b180c4ea87f24a28e67fe6e018`。
- 运行网格与完整转换矩阵的校验信息见 `geometry_report.json`。

制作源仅保留传感器网格及三个可移除文字对象，删除默认立方体、灯光和相机；原工程文件没有改写。原始 STL／官方 STEP 没有重复打包，运行与重新导出都不需要其他机器人工作空间。

配色沿用此前基于官方产品照片制作的银灰、蓝青、黑色和紧固件材质；文字为近似重建，并非精确品牌字体，没有添加序列号或认证号。转换为 COLLADA Phong 材质以兼容 Gazebo 和 RViz，不声称保留 Blender PBR 的全部渲染语义，更不代表 LiDAR 光谱反射率标定。

## 坐标与尺寸

参考 [Livox Mid-360 User Manual v1.2，2024.04](https://terra-1-g.djicdn.com/851d20f7b9f64838a34cd02351370894/Livox/Livox_Mid-360_User_Manual_EN.pdf)，印刷页 12、15、19。手册文件 SHA256 为 `3f202c845330023d50eee086cc522918ec8b1279446c4286ea3d38722400cab2`；手册仅作为本地参考缓存，不随模型安装分发。

| 坐标项 | 本包约定或官方名义值 |
|---|---|
| 安装原点 | 外壳安装底面中心 |
| +X／+Z | +X 朝向正面标识侧（接口在 -X），+Z 垂直安装底面向上；+Y 满足右手系 |
| 雷达测量原点相对安装原点 | `(0, 0, 0.047)` m，来自手册尺寸图 |
| IMU 相对雷达测量原点 | `(0.011, 0.02329, -0.04412)` m，手册明确给出，轴向相同 |
| IMU 相对安装原点 | `(0.011, 0.02329, 0.00288)` m，由上两项相加得到 |

原网格存在约两度倾斜。导出工具根据盖顶平面法线、前壳侧面法线及安装底面顶点确定刚体变换，消除倾斜并平移到底面中心；不做非均匀缩放。主体保留原有 84099 个三角形，包含文字后共 84766 个三角形、9 个材质。

导出后的整体包围盒约为 **72.737 × 64.874 × 60.127 mm**，其中长度包含接口凸出；手册给出的含接口名义长度为 73 mm，主体名义外形为 65×65×60 mm。底面归零，尺寸检查容差为 0.5 mm。网格对齐是根据几何参考面完成的配准，不是对某台实物的制造误差或外参标定。

碰撞保留为两个基础几何体：65×65×60.2 mm 盒体，以及接口位置的半径 6.2 mm、长度 8 mm 圆柱，测试覆盖全部可视顶点。精细网格不作为物理碰撞网格。总质量使用官方标称 0.265 kg，质心及惯量仍为均匀盒体近似，不能称为 CAD 实测惯量。

## 可复现导出

使用 Blender 5.2.2 批处理，不操作用户当前打开的 Blender 场景：

```bash
blender -b --factory-startup --python scripts/export_mid360_blender.py -- \
  --source meshes/mid360/source.blend --output-dir run/reexport
```

本机验证重新导出的 DAE 与收录文件 SHA256 一致。运行安装仅包含 DAE、几何报告和本说明，不安装制作源 `.blend`。Blender 仅用于资产制作，不是仿真运行依赖。
